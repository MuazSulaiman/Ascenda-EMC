# Sample Request Workflow — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Spec:** `docs/superpowers/specs/2026-08-13-sample-request-workflow-design.md` — the design/decision doc (why each choice was made, full Decision Log). This file breaks that design into sequential, self-contained implementation tasks. Each `## Task N` section is extracted verbatim as a task brief — it must be readable without any other section of this file, so it repeats exact values (schema, signatures, guard clauses) rather than pointing back at the spec.

## Global Constraints (apply to every task)

- **Reference implementation**: `app_pages/quotation_helpers.py`,
  `app_pages/quotation_request.py`, `app_pages/quotation_review.py`,
  `app_pages/quotation_handoff.py`, and `migrations/quotations_schema.sql`
  are the pattern to mirror throughout. When a task says "mirror `X`", read
  that function/file in full first and match its idiom exactly: naming,
  the single-`engine.begin()`-block guarded-`UPDATE ... RETURNING` idiom,
  `try/except Exception as e: return False, str(e)` around every transition
  function, `_require_role` as the first line of every manager/coordinator
  function, notification calls inside the same transaction as the status
  change, `_norm()`/`_sql_val()` (from `app_pages.change_request_helpers`)
  for every nullable field written to SQL.
- **No pricing.** Sample requests have no `unit_price`, `discount_pct`,
  `vat_rate`, `subtotal`/`vat_amount`/`grand_total` anywhere — do not port
  any of the `compute_line_total`/`compute_header_totals`/`Decimal` money
  machinery from quotations.
- **No `Type` (Sample/Demo) field.** Every request is implicitly a sample;
  do not add a type column, dropdown, or constant anywhere.
- **No expected-return-date field, no serial/batch/warehouse-location
  columns anywhere in the schema.** That data lives only on the exported
  Excel pick sheet (Task 3), never in a table.
- **No new role.** `sales coordinator` already exists on `users.role` — do
  not touch `admin_users.py` or any role CHECK constraint.
- **Status enum** (identical set to quotations, plain `TEXT CHECK`, not a
  Postgres enum type — match how `quotation_requests.status` is actually
  defined today, not the enum an earlier quotations draft considered):
  `IN_REVIEW`, `EDIT_REQUESTED`, `REJECTED`, `APPROVED`, `DONE`, `WITHDRAWN`.
- **Event types**: `SUBMITTED`, `RESUBMITTED`, `EDIT_REQUESTED`, `APPROVED`,
  `REJECTED`, `WITHDRAWN`, `RETURNED_FOR_REVISION`, `MARKED_DONE`.
- **Request numbering**: `f"SDR-{year}-{seq:06d}"`, assigned once at first
  submit via a `sample_request_number_counters` atomic upsert counter
  (mirror `_next_quotation_number` exactly, renamed).
- **Notifications**: every call uses `category="sample_request"`. Reuse
  `notify_users`/`notify_role` from `app_pages/notification_helpers.py`
  unchanged (do not modify that file).
- **DB access**: reuse `engine` from `db.py` and `query_df`/`query_scalar`/
  `exec_sql` from `db_ops.py` — never open a raw connection another way.
- **UI toggle pattern**: `st.radio(horizontal=True)` for tab-like toggles,
  never `st.tabs()` (resets on rerun — documented gotcha in this codebase).
- **Commits**: one commit per task (more if natural), message prefixed
  `feat:` (or `test:` for test-only tasks), following this repo's commit
  style (see `git log --oneline -10` for examples). Do not amend prior
  commits.
- **Every task that touches DB code must actually run against the live dev
  database** configured via `.env`/`DATABASE_URL` (same DB the app and the
  existing `tests/test_quotation_workflow_race.py` use) — this is how the
  Quotations tables were verified when they were built. Clean up any rows
  you insert for manual verification unless they're inside a self-cleaning
  pytest fixture.

## Task 1: Database schema and migration wiring

Create the additive schema for Sample Requests, following the exact loading
convention already used for Quotations.

**1a. Create `migrations/sample_requests_schema.sql`** with this DDL, in
this order (foreign keys require it):

```sql
CREATE TABLE IF NOT EXISTS sample_requests (
    sample_request_id  BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    request_number      TEXT    NOT NULL UNIQUE,
    customer_id           INTEGER NOT NULL REFERENCES customers(customer_id),
    rep_user_id            INTEGER NOT NULL REFERENCES users(user_id),

    request_date            DATE    NOT NULL DEFAULT CURRENT_DATE,
    remarks                   TEXT,

    status  TEXT NOT NULL DEFAULT 'IN_REVIEW' CHECK (status IN (
                 'IN_REVIEW', 'EDIT_REQUESTED', 'REJECTED', 'APPROVED', 'DONE', 'WITHDRAWN'
             )),
    version  INTEGER NOT NULL DEFAULT 0,

    submitted_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    submitted_by  INTEGER NOT NULL REFERENCES users(user_id),

    manager_user_id      INTEGER REFERENCES users(user_id),
    manager_decided_at   TIMESTAMPTZ,
    manager_comment       TEXT,

    coordinator_user_id      INTEGER REFERENCES users(user_id),
    coordinator_done_at       TIMESTAMPTZ,
    coordinator_note           TEXT,
    odoo_reference               TEXT,

    withdrawn_at       TIMESTAMPTZ,
    withdrawn_by        INTEGER REFERENCES users(user_id),
    withdrawal_reason    TEXT,

    is_deleted   BOOLEAN NOT NULL DEFAULT FALSE,
    deleted_at    TIMESTAMPTZ,
    deleted_by     INTEGER REFERENCES users(user_id)
);

CREATE UNIQUE INDEX IF NOT EXISTS idx_sr_odoo_ref_unique
    ON sample_requests (odoo_reference) WHERE odoo_reference IS NOT NULL;

CREATE TABLE IF NOT EXISTS sample_request_lines (
    line_id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sample_request_id  BIGINT NOT NULL REFERENCES sample_requests(sample_request_id) ON DELETE CASCADE,
    line_no            SMALLINT NOT NULL CHECK (line_no BETWEEN 1 AND 50),
    product_id         TEXT NOT NULL REFERENCES items(product_id),
    quantity           INTEGER NOT NULL CHECK (quantity > 0),
    delivery_date      DATE,
    created_at         TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (sample_request_id, line_no)
);

CREATE TABLE IF NOT EXISTS sample_request_revisions (
    revision_id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sample_request_id   BIGINT NOT NULL REFERENCES sample_requests(sample_request_id) ON DELETE CASCADE,
    revision_no         SMALLINT NOT NULL,
    created_at           TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by            INTEGER NOT NULL REFERENCES users(user_id),
    customer_id            INTEGER NOT NULL REFERENCES customers(customer_id),
    request_date            DATE NOT NULL,
    remarks                   TEXT,
    UNIQUE (sample_request_id, revision_no)
);

CREATE TABLE IF NOT EXISTS sample_request_revision_lines (
    revision_line_id        BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    revision_id              BIGINT NOT NULL REFERENCES sample_request_revisions(revision_id) ON DELETE CASCADE,
    line_no                    SMALLINT NOT NULL,
    product_id                  TEXT NOT NULL REFERENCES items(product_id),
    article_number_snapshot      TEXT,
    description_snapshot          TEXT,
    quantity                        INTEGER NOT NULL,
    delivery_date                    DATE
);

CREATE TABLE IF NOT EXISTS sample_request_status_events (
    event_id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    sample_request_id   BIGINT NOT NULL REFERENCES sample_requests(sample_request_id) ON DELETE CASCADE,
    event_type          TEXT NOT NULL CHECK (event_type IN (
                             'SUBMITTED', 'RESUBMITTED', 'EDIT_REQUESTED', 'APPROVED',
                             'REJECTED', 'WITHDRAWN', 'RETURNED_FOR_REVISION', 'MARKED_DONE'
                         )),
    actor_user_id       INTEGER NOT NULL REFERENCES users(user_id),
    from_status          TEXT,
    to_status              TEXT NOT NULL,
    comment                  TEXT,
    revision_id               BIGINT REFERENCES sample_request_revisions(revision_id),
    at_utc                      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS sample_request_number_counters (
    year     INTEGER PRIMARY KEY,
    last_seq INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_sr_status        ON sample_requests(status);
CREATE INDEX IF NOT EXISTS idx_sr_rep            ON sample_requests(rep_user_id);
CREATE INDEX IF NOT EXISTS idx_sr_customer       ON sample_requests(customer_id);
CREATE INDEX IF NOT EXISTS idx_sr_manager        ON sample_requests(manager_user_id);
CREATE INDEX IF NOT EXISTS idx_sr_coordinator    ON sample_requests(coordinator_user_id);
CREATE INDEX IF NOT EXISTS idx_srl_request       ON sample_request_lines(sample_request_id);
CREATE INDEX IF NOT EXISTS idx_srl_product       ON sample_request_lines(product_id);
CREATE INDEX IF NOT EXISTS idx_srev_request      ON sample_request_revisions(sample_request_id, revision_no);
CREATE INDEX IF NOT EXISTS idx_srse_request      ON sample_request_status_events(sample_request_id, at_utc);
CREATE INDEX IF NOT EXISTS idx_sr_customer_done  ON sample_requests(customer_id, status) WHERE status = 'DONE';
CREATE INDEX IF NOT EXISTS idx_sr_rep_done       ON sample_requests(rep_user_id, status) WHERE status = 'DONE';
```

## Task 3: Pick-sheet Excel export and manager-insights queries

Extends `app_pages/sample_request_helpers.py` from Task 2 (read that file
first — it now exists). Add:

- **`generate_sample_pick_sheet(sample_request_id: int) -> bytes`** — new
  function, no quotation equivalent to mirror (quotations use PyMuPDF for a
  PDF; this is a fresh `.xlsx` via `openpyxl`, which is not yet a
  dependency used elsewhere in `app_pages/` — check `requirements.txt` for
  `openpyxl` and add it if missing, pinning to whatever version resolves
  cleanly; do not touch any other pinned version in that file given the
  recent segfault history visible in `git log --oneline -10`).
  Implementation:
  1. Load the header via `_load_sample_request_header` and lines via
     `_load_sample_request_lines`; raise `ValueError` if status is not in
     `("APPROVED", "DONE")`.
  2. Look up the customer name (`customers.account_name`) and, for each
     line, the item's `article_number`/`description` from `items`.
  3. Build one `openpyxl.Workbook()`, one sheet named `"Warehouse Pick
     Sheet"`. Header rows: `Request No: <request_number>`, `Date:
     <request_date>`, `Customer: <account_name>`. Blank row. Column header
     row: `SI.NO`, `Model No`, `Item Description`, `Unit`, `Delivery Date`,
     `Serial/Batch Number`, `Warehouse Name`, `Warehouse Location`.
  4. For each line (in `line_no` order), for `k` in `1..quantity`: one data
     row — `SI.NO` = the line's `line_no`, `Model No`/`Item Description`
     from the item lookup, `Unit` = `f"{k} of {quantity}"`, `Delivery Date`
     = the line's `delivery_date` (blank if null), and the last three
     columns left blank for hand-filling.
  5. Save to an `io.BytesIO()` buffer via `wb.save(buffer)`, return
     `buffer.getvalue()`.
- **`get_rep_sample_stats(rep_user_id: int) -> dict`** — returns
  `{"all_time_qty": int, "this_month_qty": int, "recent": list[dict]}`.
  `all_time_qty`/`this_month_qty` come from
  `SELECT COALESCE(SUM(srl.quantity), 0) FROM sample_requests sr JOIN
  sample_request_lines srl ON srl.sample_request_id =
  sr.sample_request_id WHERE sr.rep_user_id = :rep_user_id AND sr.status =
  'DONE' [AND sr.coordinator_done_at >= date_trunc('month',
  CURRENT_DATE)]` (the bracketed clause only for `this_month_qty`). Use
  `query_scalar`. `recent` = last 5 `DONE` requests by this rep ordered by
  `coordinator_done_at DESC`, each dict with `request_number`,
  `coordinator_done_at`, `customer_name` (join `customers`), and
  `total_qty`/`item_summary` (aggregate `sample_request_lines` per
  request — `item_summary` is a comma-joined string like `"Model A x2,
  Model B x1"`, built in Python from a per-request line query, not SQL
  string aggregation). Return `{"all_time_qty": 0, "this_month_qty": 0,
  "recent": []}` (no error) when the rep has zero `DONE` history.
- **`get_customer_sample_stats(customer_id: int) -> dict`** — identical
  shape to `get_rep_sample_stats`, but filtered by `sr.customer_id =
  :customer_id` with **no** `rep_user_id` filter (deliberately spans all
  reps), and each `recent` entry additionally includes `rep_name` (join
  `users`).

**Tests**: create `tests/test_sample_pick_sheet_export.py` and
`tests/test_sample_request_insights.py` (self-cleaning fixtures against
the live dev DB, same style as Task 2's smoke tests):
- Pick-sheet: a multi-line request with quantities `[2, 1, 5]` produces
  exactly 8 data rows; the `Unit` column reads `"1 of 2"`..`"2 of 2"` for
  the first line, etc.; calling it on an `IN_REVIEW` request raises
  `ValueError`.
- Insights: a `DONE` request counts toward `all_time_qty`; an `APPROVED`
  (not yet `DONE`) request does NOT count; a `DONE` request with
  `coordinator_done_at` backdated to last month (update it directly via
  SQL in the test fixture) counts in `all_time_qty` but NOT in
  `this_month_qty`; two different reps' `DONE` requests to the same
  customer both count toward that customer's `all_time_qty` (cross-rep
  scoping); a rep/customer with zero history returns all-zero, not an
  error.
